# 米拉星系数据

## 该星系内已知存在5个行星
- 米拉-I 一颗岩石行星，有氢气大气，富含金属与岩石矿物以及晶体矿，米拉星人在此进行采矿以获取矿物资源
- 米拉-II 荒芜星球，地表发现了中子物质，米拉星人开采中子用于制造混合中子材料与科研工作所需
- 米拉-III 又名米拉星，宜居星球，在最后数据中有超过160亿只米拉星人定居此处，它有一颗小卫星，作为米拉星人的星际探索中转站
- 米拉-IV  气态巨星，提供极为丰富的氢和氦资源,其卫星群富含稀有矿物
- 米拉-V 矮行星，那里有一座低重力科研站

## 已知数据
- 数百年前，一队喵星人星际探索舰队漂流至一个红矮星星系，那里的恒星被命名为“米拉”，其质量约为太阳系中太阳的0.65倍
- 他们定居后持续发展，走向了与喵星人不同的科技树
- 他们没有曲速引擎，一开始带来的曲速飞船已经被拆解用于建造定居点，而是利用米拉-I的中子物质发现了人造虫洞折跃的可能性
- 喵星系统内没有天然中子物质矿，喵星科学家只能人工合成少量中子物质，因此我们没有研究人造虫洞技术
- 米拉星系于1066年爆发未知瘟疫，米拉星系当局于一个月后关闭米拉星门，与喵星系统的联系彻底中断
