# 干员属性

## 战斗规则与说明

- 爆炸伤害也分物理爆炸和能量爆炸<br>物理爆炸 额外造成10% 能量伤害<br>能量爆炸 额外造成10% 物理伤害

- 魔法攻击本身没有魔法伤害<br>(我懒得做)，同时造成<br>100%的物理和能量伤害<br>并且无视护甲(Armor)

- 护盾只能抵挡特定类型的伤害<br>可抵挡魔法的护盾，与全能型护盾<br>对魔法伤害自带20%免伤，<br>与其他免伤效果分开计算<br>全能型包含物理、能量、魔法和爆炸防护

- 每一种不同的免伤效果都是独立计算的<br>护甲通常先于HP受伤<br>护盾先于护甲，例外单独说明<br>护盾自己的免伤，<br>只对作用到护盾上面的伤害有效

- 如果某种攻击带有10%护盾穿透<br>它会对护盾造成90%伤害，<br>剩余10%穿过护盾<br>其他数值同理

- 无论免伤叠的有多高，<br>最低单次伤害永远是1

- ATK每高于目标DEF 10, 伤害就+1%<br>DEF每高于目标ATK 10，伤害-1%<br>最大增减益比例是+300% / -70%

- 如果地面载具被摧毁，驾驶员会安全弹出<br>空中载具则会跳伞<br>太空载具有逃生舱（超级地狱俯冲!）

- 爆炸伤害后面的# x / y<br>表示它的爆炸内半径是x米，外半径y米<br>内半径造成100%伤害，<br>外半径随着距离比例增加而逐渐衰减到0

- [超级爆炸]词条：<br>对Boss级别目标造成2倍伤害<br>并且对任何目标都无视护盾

- 魔法护盾的20%免伤，指的是对魔法攻击<br>包含的物理与能量伤害同时-20%<br>然后再作用于护盾<br>（如果护盾可以抵挡物理或能量）<br>防爆护盾也是同理，爆炸也同时含有两种

- 一次伤害同时包含物理和能量伤害时<br>它们会一起生效，分别被对应的效果增减

- 真实伤害无视护盾护甲和免伤，<br>直接攻击血条<br>但是同一目标每秒钟只能受到1次真实伤害<br>如果同时出现多次，取最高的那个<br>1秒内先后到来的，取最先来的


- 伤害减免只对HP（血条）生效<br>护盾的减免是独立的特定计算

- AP&amp;AV:<br>AP指穿甲等级，AV指装甲等级<br>攻击的AP必须大于目标护甲AV，才能造成伤害，否则护甲会将伤害无效化<br>若AP = AV，则只造成80%伤害<br>未标注的AP和AV默认为1

- 护盾的AV全部是0
