# 快速开始

## 启动本地站点

在项目根目录执行：

```sh
npm install
npm run docs:dev
```

打开终端输出的地址，即可查看站点。修改文档后，开发服务器会自动更新页面。

## 编写文档

所有页面都位于 `docs/` 目录，使用 Markdown 编写：

```md
# 页面标题

这里是正文，可以使用 **加粗**、列表和链接。

## 二级标题

这里填写具体内容。
```

VitePress 也支持提示框：

::: info 示例
你可以使用提示框展示补充说明、注意事项或操作建议。
:::

## 添加新页面

1. 在 `docs/data_public/` 下新建 Markdown 文件，例如 `faq.md`。
2. 在 `docs/.vitepress/config.mts` 的 `sidebar` 中添加链接 `/data_public/faq`。
3. 如需新增顶部栏目，修改同一配置文件中的 `nav`。

## 构建与预览

```sh
npm run docs:build
npm run docs:preview
```

生产文件输出到 `docs/.vitepress/dist/`，可以交给静态网站托管服务发布。

## GitHub Pages 部署

完整上传和部署步骤见项目根目录 `README.md`。GitHub Actions 会自动获取 Pages 的子路径并构建部署，无需手动修改配置中的 `base`。

本地模拟子路径时设置 `VITEPRESS_BASE` 环境变量，例如 `/Hikariers_wiki/`。构建完成后运行 `npm run docs:check` 检查页面链接和资源；构建与检查需使用相同的环境变量。

此说明不生成网站页面，但在公开 GitHub 源码仓库中仍然可见。
